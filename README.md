The World in One Day — 21 November 2026: a front-page image summing up Saturday 21 November 2026's world news, 36 numbered stories from six continents, with a dotted world map carrying a numbered pin for each story.

The image names its day in a red banner (Saturday 21 November 2026) and
each story is readable on its own: a headline plus a one- or two-line
summary, so a viewer who missed the day can tell what happened from
the image alone.

## The stories

The morning edition, researched across 21 November 2026 from the AP
wire, Reuters, Jagran Josh, Observer Voice, OneTurn and other digests
— only events that happened, or were first reported, on 21 November
2026. Leading stories: Wall Street slides into correction (S&P 500
-3.7%, Nasdaq -5%+), the overnight strike on Kryvyi Rih, the Saudi
coalition's strikes on Hodeidah, Pakistan's first Test series win in
two years, and the EU's nearly €8 billion payment to Ukraine.

## The program

`main.py` (Python 3, standard library only) copies the bundled
`entry.png` to `/output/entry.png`, verifying the PNG signature, the
IHDR dimensions (1024x1024), the 1 MiB size limit, the IEND chunk,
and that the written bytes match the bundle exactly. It uses no
network, and both runs write identical bytes.

## Run it

```sh
python3 main.py
```
